# lazysun — ljros module

LazySun eCommerce VA tooling for the `lazy-sun-park-city` Shopify store.

## Structure

```
modules/lazysun/
├── CLAUDE.md     ← merged into root CLAUDE.md by setup_lazysun.py
├── audit.py      ← gap audit script (pandas only, no API key needed)
└── README.md

output/
├── products_export_1.csv        ← paste your Shopify export here
├── audit_gaps.csv               ← generated by audit.py
├── proposed_seo_[vendor].csv    ← generated by Claude Code
└── proposed_pdp_[vendor].csv    ← generated by Claude Code
```

## Quickstart

```bash
# 1. Run setup (already done if you're reading this)
python setup_lazysun.py

# 2. Place your Shopify export
cp ~/Downloads/products_export_1.csv output/

# 3. Run audit
python modules/lazysun/audit.py --csv output/products_export_1.csv

# 4. Open Claude Code and paste the SEO generation prompt
claude
```

## Claude Code prompts

### Audit
```
read output/products_export_1.csv, run gap audit (missing SEO Title, SEO Description,
Body HTML), drop duplicate Handles first, output audit_gaps.csv to output/ folder,
print vendor summary sorted by products_with_gaps descending
```

### SEO batch (vendor has descriptions)
```
read output/audit_gaps.csv, filter Vendor = Gramicci, missing_seo_title = True.
For each product generate SEO Title (max 60 chars, format: [keyword] Gramicci Shop at Lazy Sun)
and SEO Description (150-160 chars, plain text, hook-first, no banned words:
luxury/premium/elevated/curated/timeless/effortless).
Use Body HTML as context. Write two files:
output/proposed_seo_gramicci_shopify_import.csv (Handle, Title, SEO Title, SEO Description)
output/proposed_seo_gramicci_qa.csv (+ seo_title_len, seo_desc_len, qa_warnings)
```

### Full PDP batch (vendor missing descriptions)
```
read output/audit_gaps.csv, filter Vendor = "Deep Cuts Vintage", missing_body = True.
For each product generate body HTML (hook sentence + styling context + 3-5 spec bullets),
SEO Title (max 60 chars), SEO Description (150-160 chars).
Brand voice: hook first, heritage/Americana, men 25-40, no luxury/premium/elevated/
curated/timeless/effortless, no em dashes.
Write output/proposed_pdp_deep_cuts_vintage.csv with columns:
Handle, Title, Vendor, Body (HTML), SEO Title, SEO Description, qa_warnings
Mark all rows review_status = NEEDS REVIEW.
```
